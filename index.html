Poima Studio

株式会社ポイマが自社の YouTube チャンネルを運営するための社内ツールです。
An in-house tool Poima Inc. uses to operate its own YouTube channels.

これは何か / What this is

Poima Studio（OAuth クライアント名: nemurigatari）は、株式会社ポイマが自社で保有する YouTube チャンネルに動画を投稿・管理するために自社開発した、社内向けの自動化ツールです。 一般に公開されたサービスではなく、第三者にアカウントを接続させたり、第三者へデータを提供したりすることはありません。

Poima Studio (OAuth client name: nemurigatari) is an in-house automation tool built by Poima Inc. to upload and manage videos on YouTube channels that we own. It is not a consumer product: no third party can connect an account to it, and we do not provide data to any third party.

YouTube API の利用について / Use of the YouTube API

本ツールは YouTube Data API を、自社チャンネルに対する以下の操作に限って利用します。

操作 / Operation用途 / Purpose
動画のアップロードと状態の確認 自社チャンネルへの動画の投稿（公開予約を含む）と、処理状況の確認。
Uploading videos to our own channels (including scheduled publishing) and checking their processing status.
サムネイル・再生リスト 投稿した動画のサムネイルの設定と、再生リストへの追加。
Setting thumbnails for our videos and adding them to our playlists.
チャンネル設定 自社チャンネルの説明文などの設定の読み取りと更新。
Reading and updating settings, such as the description, of our own channels.

YouTube 利用規約に従って利用します。 We use the API in accordance with the YouTube Terms of Service.
